# Classroom AI-dventure

Classroom AI-dventure is an educational 2D adventure game developed in Java using Java Swing. The game explores the role of artificial intelligence in education through an interactive classroom narrative, decision-making scenarios, and knowledge-based challenges.

Players take on the role of AI-Den, an artificial intelligence teaching assistant designed to support a classroom teacher. Throughout the game, players interact with students, make decisions, and complete educational challenges that test both their knowledge and their ability to respond appropriately to different situations.

## Gameplay

The game consists of three levels, each focusing on a different aspect of AI-assisted education.

### Level 1 — The AI Teacher

The game begins in a classroom where Mr. Avetsark, a teacher who is overwhelmed by the number of questions from his students, decides to introduce an AI teaching assistant.

This level establishes the game's story and introduces the concept of using AI as a tool to support teachers and students.

### Level 2 — Teaching and Empathy

Players take control of AI-Den and interact with students throughout the classroom.

Students present different situations, and players must select appropriate responses. Their decisions affect their score and demonstrate the importance of empathy, communication, and constructive feedback in an educational environment.

### Level 3 — AI Training Simulation

AI-Den enters a simulated training environment containing questions covering mathematics, science, and general knowledge.

Players move AI-Den around the environment and select the answer they believe is correct.

- Correct answers increase the player's score.
- Incorrect answers result in a strike.
- Players attempt to achieve the highest score possible.

## Running the Game

### Requirements

- Java 21 or later

The game is compiled for Java 21 and requires Java 21 or a compatible newer version to run the packaged JAR.

### Running the JAR

After downloading the JAR file, open a terminal in the directory containing the file and run:

```bash
java -jar SSDStudios_FinalISP.jar
```

The game may also be launched by double-clicking the JAR file if Java is properly configured on the system.

The project explores the potential role of artificial intelligence in education while emphasizing that effective teaching involves more than simply providing correct information.

The game addresses several concepts, including:

- Artificial intelligence in education
- Human-AI interaction
- Communication and empathy
